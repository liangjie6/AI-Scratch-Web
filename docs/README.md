## 维护规则

1. 修改运行时协议、AI 提示词或 Scratch 包版本时，必须同步更新对应参考文档与测试。
2. 新的实施方案应明确状态、适用版本和替代关系；完整替代旧方案后，删除旧稿或移动到研究归档。
3. 所有新增文档从本索引链接；引用仓库内文件时使用相对 Markdown 链接。
