## 决策记录（已与需求方确认）

1. 生成基线：默认"从新项目生成"，可切换"在当前项目上增量生成"。
2. 无"计划确认"步骤，仅生图前弹确认。
3. AI 交给 VM 解析并由 VM 分批注入积木（编辑器内实时可见），不自动运行演示。
4. 模块失败带错误原因重试，最多 3 次；3 次后停止任务，此前成功模块全部保留，失败模块可单独重试或继续对话。
5. 撤销为模块级 + 会话级回退双通道。
6. 内置素材缺失且用户拒绝生成时：跳过该素材项，继续后续模块。
7. 对话上下文自动压缩摘要。
8. 用户示例中 Pico、Star、Stars 均存在于内置库（`frontend/public/assets/scratch/libraries/sprites.json` 已验证），不触发图像生成。
